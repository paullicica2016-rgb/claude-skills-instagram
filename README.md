# 5 skill-uri Claude pentru Instagram

Cele 5 skill-uri din reelul meu, care îl transformă pe Claude în echipa ta de conținut.
Le-am testat pe zeci și pe astea le folosesc.

| Skill | Ce face |
|---|---|
| **reel-builder** | Îți scrie tot reelul: hook-ul, fiecare scenă, textul de pe ecran și descrierea |
| **carousel-builder** | Carusel de 8–10 slide-uri, de la copertă până la slide-ul pe care oamenii îl salvează |
| **caption-and-hashtags** | Descrierea (cu prima frază care te face să apeși „mai mult”), hashtag-urile și primul comentariu |
| **bio-profile-optimizer** | Îți analizează profilul și îți rescrie bio-ul și numele, ca vizitatorii să te urmărească |
| **comment-responder** | Îți scrie răspunsul la fiecare comentariu (fără linkuri în public) și mesajul pe care îl trimiți în privat |

## Cum le instalezi (Claude Code)

1. Apasă butonul verde **Code → Download ZIP** și dezarhivează.
2. Copiază folderele din `skills` în:
   - **Windows:** `C:\Users\numele-tău\.claude\skills`
   - **Mac:** `~/.claude/skills`

   (dacă folderul `skills` nu există, creează-l)
3. Repornește Claude Code și scrie numele skill-ului și ce vrei:

```
/reel-builder un reel despre 3 greșeli în Google Ads, pentru antreprenori. Răspunde în română.
```

## Nu folosești Claude Code?

Intră în folderul `skills`, deschide skill-ul dorit, apoi fișierul `SKILL.md`. Copiază tot textul în
[claude.ai](https://claude.ai) și scrie dedesubt ce vrei.

**Sfat:** adaugă mereu „Răspunde în română”, altfel îți poate răspunde în engleză.

## De știut

- **comment-responder** îți scrie răspunsurile și mesajele. Trimiterea automată în privat are nevoie de un
  tool separat (de exemplu ManyChat); fără el, le trimiți tu.
